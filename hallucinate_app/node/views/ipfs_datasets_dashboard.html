Module Information

The IPFS Datasets module provides seamless integration between HuggingFace datasets and IPFS. It enables efficient loading, caching, and sharing of datasets through the IPFS network.

Key Features:

  • HuggingFace Integration: Direct access to thousands of datasets from the HuggingFace Hub
  • IPFS Storage: Store and retrieve datasets using content-addressed IPFS storage
  • Efficient Caching: Smart caching mechanisms to reduce download times
  • Dataset Discovery: Browse and search available datasets
  • Streaming Support: Stream large datasets without full downloads
  • Version Control: Track dataset versions through IPFS content IDs

    Documentation & Resources

    API Endpoints:

    • /health - Liveness check for the datasets service
    • /health/ready - Readiness check for tool and dependency availability
    • /datasets/list - List available datasets
    • /datasets/load - Load a dataset from HuggingFace or IPFS
    • /datasets/info - Get dataset metadata
    • /datasets/cache - Manage dataset cache
    Note: Ensure the IPFS Datasets MCP server is running to use these features. Start it from the Daemons menu or the Daemon Manager.
    Dashboard Integration: The active IPFS Datasets FastAPI MCP service on port 3002 exposes the dataset APIs, while the native package MCP dashboard is launched as a companion service and embedded below from http://127.0.0.1:8899/mcp.
