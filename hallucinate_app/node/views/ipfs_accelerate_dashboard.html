Module Information

The IPFS Accelerate module provides performance-optimized AI model serving and inference capabilities. It combines the power of HuggingFace's Accelerate library with IPFS for decentralized model distribution and serving.

Key Features:

  • Fast Model Loading: Optimized loading of models from IPFS with intelligent caching
  • Multi-Model Support: Manage and serve multiple models simultaneously
  • Hardware Acceleration: Automatic GPU/TPU utilization when available
  • Distributed Inference: Split model inference across multiple nodes
  • Efficient Memory Management: Smart memory allocation and model offloading
  • Real-time Monitoring: Track model performance and resource usage

    Documentation & Resources

    API Endpoints:

    • /models/load - Load a model from IPFS or HuggingFace
    • /models/list - List currently loaded models
    • /inference - Run inference on a loaded model
    • /models/unload - Unload a model from memory
    • /health - Check server health and status
    • /metrics - Get performance metrics
    Performance: IPFS Accelerate uses multi-process architecture to prevent IPFS operations from blocking model inference, ensuring optimal performance.
    Note: Ensure the IPFS Accelerate MCP server is running to use these features. Start it from the Daemons menu or the Daemon Manager.
