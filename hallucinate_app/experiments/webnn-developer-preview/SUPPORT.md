# WebNN Developer Preview Support

## How to file issues and get help

This WebNN Developer Preview experiment uses
[GitHub Issues](https://github.com/endomorphosis/hallucinate_app/issues) to
track bugs and feature requests. Search existing issues before opening a new
one to avoid duplicates.

When filing an issue, include:

- The demo or model you were running.
- Browser name and Chromium version from `about://version`.
- Operating system version and whether the WebNN flag is enabled.
- Steps to reproduce the problem, expected behavior, actual behavior, and any
  console output.

For questions about contributing, see the contributing guidance in
`README.md`. Code of conduct questions can be sent to
[opencode@microsoft.com](mailto:opencode@microsoft.com).

## Microsoft Support Policy

This experiment is provided as a developer preview and is not covered by a
Microsoft Customer Service and Support plan. Support is limited to the GitHub
Issues workflow described above.
